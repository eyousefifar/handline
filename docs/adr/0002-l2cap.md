# ADR 0002 — BLE L2CAP for the byte stream

The public category uses a Bluetooth LE link. L2CAP connection-oriented channels carry whole SDUs, which matches "one frame per write" and a PSM printed in the QR code. Classic RFCOMM is not a second hidden path. If a live link cannot hold 16 kbit/s Opus, audio stops and call state remains.

Status: accepted.
